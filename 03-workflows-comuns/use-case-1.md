# 👩‍💻 Workflow de Exploração e Planejamento

## 🎯 Objetivo

Resolver problemas complexos com etapas bem definidas usando Claude Code.

## Passos

1. Peça para Claude ler arquivos relevantes e entender o contexto
2. Solicite um plano detalhado de ação
3. Revise o plano antes de pedir a implementação
4. Peça para Claude implementar a solução
5. Teste, commite e abra um Pull Request

## Exemplo de Prompt

> "Claude, leia o arquivo logging.py, pense e proponha um plano para melhorar o sistema de logs. Não escreva código ainda."
