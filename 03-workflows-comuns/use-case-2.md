# 👩‍💻 Workflow TDD (Test Driven Development)

## 🎯 Objetivo

Garantir qualidade e segurança no desenvolvimento usando testes automatizados.

## Passos

1. Peça para Claude escrever testes baseados nos requisitos
2. Execute os testes e confirme que falham (sem implementação)
3. Peça para Claude implementar o código até que todos os testes passem
4. Commite os testes e a implementação

## Exemplo de Prompt

> "Claude, escreva testes unitários para a função de autenticação. Não implemente a função ainda."
