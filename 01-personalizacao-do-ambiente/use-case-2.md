# 👩‍💻 Dicas de Configuração para CLAUDE.md

## 🎯 Objetivo

Ajudar a criar um CLAUDE.md eficiente e útil para toda a equipe.

## 🔍 Boas Práticas

- **Seja específico:** Documente comandos e padrões realmente usados no projeto.
- **Atualize sempre:** Revise o arquivo a cada mudança relevante no fluxo de trabalho.
- **Inclua instruções de ambiente:** Exemplo: versões de Node, Python, variáveis de ambiente, etc.
- **Evite excesso de informação:** Prefira clareza e objetividade.

## Exemplo

```md
# Ambiente
- Node.js v18+
- Variável de ambiente: NODE_ENV=development

# Testes
- Rode `npm run test` antes de abrir PR
```
