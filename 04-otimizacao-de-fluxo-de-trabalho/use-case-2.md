# 👩‍💻 Uso de Imagens e Arquivos

## 🎯 Objetivo

Aumentar a precisão das respostas do Claude fornecendo contexto visual ou textual.

## Exemplos

- Cole um screenshot de um erro para Claude analisar
- Anexe um arquivo de log para depuração
- Forneça o caminho de um arquivo para Claude ler e sugerir melhorias

## Dica

Quanto mais contexto, melhor a resposta do Claude!
