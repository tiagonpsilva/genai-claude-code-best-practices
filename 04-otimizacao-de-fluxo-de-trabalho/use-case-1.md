# 👩‍💻 Checklist para Correção de Lint

## 🎯 Objetivo

Organizar e acompanhar a correção de múltiplos erros de lint usando Claude Code.

## Exemplo de Checklist em Markdown

```md
- [ ] Corrigir erro em src/app.js:12
- [ ] Corrigir erro em src/utils.js:45
- [ ] Corrigir erro em src/index.js:8
```

## Dica

Peça para Claude atualizar o checklist a cada correção realizada!
