# 👩‍💻 Uso como Linter Subjetivo

## 🎯 Objetivo

Detectar problemas de legibilidade, nomes ruins e comentários desatualizados usando Claude Code em modo headless.

## Exemplo de Comando

```sh
claude -p "Revise o código em src/app.js e aponte problemas subjetivos de qualidade." --output-format stream-json
```

## Dica

Use em conjunto com linters tradicionais para uma revisão mais completa!
